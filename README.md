# Employee Data Analysis and Visualization using Python

## Project Overview
This project focuses on analyzing employee data using Python libraries. It demonstrates data cleaning, exploratory data analysis, statistical computation, and visualization to extract meaningful insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset Description
The sample dataset contains 15 employee records with the following attributes:
- Employee ID
- Name
- Department
- Age
- Salary
- Experience

## Key Features
- Data exploration using Pandas
- Handling missing values using median imputation
- Duplicate record identification and removal
- Department-wise employee analysis
- Average, minimum, and maximum salary calculations
- Statistical analysis using NumPy
- Salary distribution histogram
- Department-wise bar charts
- Experience vs. salary scatter plot
- Correlation heatmap
- Exporting cleaned data into CSV format

## Project Workflow
1. Dataset creation
2. Data exploration
3. Data cleaning and preprocessing
4. Exploratory Data Analysis (EDA)
5. Statistical analysis
6. Data visualization
7. Business insights
8. CSV export

## Key Learning Outcomes
- Practical experience with Pandas DataFrames
- Understanding NumPy statistical functions
- Data cleaning and preprocessing techniques
- Data visualization using Matplotlib
- Extracting insights from structured datasets

## How to Run
1. Download the Jupyter Notebook.
2. Open it using Google Colab or Jupyter Notebook.
3. Run the cells sequentially.
4. Explore the generated charts and analysis.
